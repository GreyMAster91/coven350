# Сайт-приглашение «350 лет Графине»

Статичный сайт: `index.html`, `style.css`, `app.js`, папка `img/`, `og-image.png`. Сборка не нужна — просто откройте `index.html`.

## 1. Заявки в Telegram
1. В Telegram напишите **@BotFather** → `/newbot` → получите токен вида `123456789:AA...`.
2. Напишите своему новому боту любое сообщение (например `/start`).
3. Откройте в браузере `https://api.telegram.org/bot<ТОКЕН>/getUpdates` и найдите `"chat":{"id": ...}` — это ваш chat id.
   (Для группы: добавьте бота в группу, напишите там сообщение; id группы начинается с `-`.)
4. В начале `app.js` заполните:
   ```js
   TG_BOT_TOKEN: '123456789:AA...',
   TG_CHAT_ID: '123456789',
   ```
Пока поля пустые, гость всё равно видит благодарность, а ответ только пишется в консоль браузера (то есть **никуда не уходит**).

⚠️ Токен лежит в клиентском JS и виден любому, кто откроет код страницы. Для вечеринки это приемлемо: худшее, что можно сделать, — заспамить бота. После праздника токен можно отозвать в @BotFather (`/revoke`).

## 2. Бесплатная публикация
- **Netlify Drop:** зайдите на https://app.netlify.com/drop и перетащите папку `coven350` (или zip). Получите адрес вида `coven350.netlify.app` (переименовать можно в Site settings).
- **GitHub Pages:** создайте репозиторий, загрузите файлы в корень, Settings → Pages → Deploy from branch `main` / root. Адрес: `https://<логин>.github.io/<репозиторий>/`.

**Превью в Telegram:** после публикации замените в `index.html` `content="og-image.png"` на полный адрес, например `https://coven350.netlify.app/og-image.png` — мессенджеры лучше понимают абсолютную ссылку.

## 3. Что заменить
- **Фото образов дресс-кода:** `index.html`, секция `#dress`, четыре `<img src="img/look-1.svg">` … `look-4.svg`. Положите свои фото в `img/` (вертикальные, 3:4) и поменяйте `src`.
- **Подсказка по навигации:** `index.html`, блок `#nav-hint` — метро и парковка; при желании добавьте, как найти вход.
- **Дата/время:** `EVENT_START`/`EVENT_END` в `app.js` (таймер) и строки `DTSTART`/`DTEND` в функции `buildICS`.
- **Обложка для соцсетей:** `og-image.png` (1200×630).

## 4. Оформление
Шрифты: Ruslan Display (заголовки) и Old Standard TT (текст) из Google Fonts. Декор — SVG в `img/`: `bat-crest.svg` (герб с летучей мышью), `rose.svg`, `filigree.svg` (уголки рамки), `divider.svg`. Цвета — переменные в начале `style.css` (`--red`, `--silver` …).
